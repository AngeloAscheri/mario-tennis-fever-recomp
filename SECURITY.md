# Security

mtf-recomp runs code generated from a game on your machine, and its tools read files you give them. If you find a
way a crafted dump, mod or setting file could make the tools or the runtime do something harmful (write outside their
folders, run other programs), please report it privately through GitHub's
[security advisories](../../security/advisories/new) instead of a public issue.

Reports about Nintendo's game itself, or requests for game files or keys, are not security issues and will be closed.
